QuadTalk プライバシーポリシー

公告・施行日 2026年10月18日

本書は翻訳版です。韓国語の原文が正本であり、内容が異なる場合は韓国語原文が優先します。

TerryWi（以下「提供者」）は、韓国「個人情報保護法」第30条に基づき、利用者の個人情報を保護し、関連する苦情を迅速かつ円滑に処理するため、以下のとおりプライバシーポリシーを定め公開します。QuadTalk（クアッドトーク）は、韓国語・英語・日本語・中国語のうち一つを基準言語とし、残りの三つの言語を一緒に学ぶ語学学習アプリです。学習記録は原則として利用者の端末にのみ保存されます。

第1条（収集・利用の目的）

提供者は、以下の目的のために必要最小限の個人情報を処理します。以下の目的以外には利用せず、目的を変更する場合は別途同意を得るなど必要な措置を講じます。

  • 主要機能の提供：QuadTalk（以下「本サービス」）のレッスン、練習・復習、ボス（レベルアップテスト）、ボーナス、学習カレンダー・統計などの学習機能とその進捗は利用者の端末にのみ保存され、この目的のために提供者が収集・保管する個人情報はありません。
  • 学習通知：利用者が決めた時刻に一日一回の学習通知を端末内で予約・表示します。外部へ送信される情報はありません。
  • バックアップ・復元（任意）：Google アカウントを連携し、利用者本人の Google ドライブに学習記録をバックアップ・復元する機能を提供します。
  • 広告の掲載：Google AdMob によるバナー広告で本サービスの運営資金を確保します。

第2条（収集する項目と方法）

収集項目

  • ［アカウント連携時・任意］Google アカウント情報：メールアドレス（または表示名）。Google アカウント連携（OAuth）後に Google ドライブから取得し、連携中のアカウントを画面に表示するためだけに使い、利用者の端末にのみ保存します。学習機能はすべてアカウント連携なしで利用でき、連携は Google ドライブのバックアップ・復元を使う場合にのみ必要です。
  • ［アプリ利用中に作成・端末内保存］設定と学習記録：基準言語、生まれた年、一日の目標、発音表記レベル、通知設定などのアプリ設定と、完了したユニット、星、テスト結果、連続学習日数、学習カレンダー、復習カード、覚えた単語数などの進捗。これらは端末のストレージにのみ保管され、提供者のサーバーには送信されません（提供者は独自のサーバーを運営していません）。
  • ［バックアップ利用時］Google ドライブのバックアップデータ：「今すぐバックアップ」を押すたびに、上記の設定と学習記録を JSON 形式で利用者本人の Google ドライブ内のアプリ専用領域（appDataFolder）に保存します。アプリが自動でバックアップすることはありません。この領域は利用者本人も Google ドライブの画面から直接閲覧できない非公開領域で、提供者を含む第三者はアクセスできません。本サービスは利用者のほかのドライブファイルを見ません。
  • ［広告 SDK による自動収集］広告 ID と端末情報：本サービスは Google AdMob でバナー広告を掲載し、その過程で広告 ID、IP アドレス（おおよその位置の推定）、端末情報、広告の表示・クリックに関する診断データが Google により収集されることがあります。これは提供者が直接収集・保管する情報ではなく、Google のプライバシーポリシーに従って処理されます。

収集方法：本サービス利用中の利用者による入力、Google アカウント連携（OAuth）、広告 SDK による自動収集。本サービスはマイク・連絡先・SMS・通話履歴・位置情報・写真など端末内のほかの個人情報にアクセスしません。

文の読み上げ：学習文を音声で再生する際、端末の音声合成（TTS）を使います。渡されるのはアプリに含まれる学習文のみで、利用者の個人情報は含まれません。

第3条（保有期間）

  • Google アカウント情報：「ログアウト」または「アカウント連携を解除してバックアップを削除」を実行すると端末から直ちに削除されます。
  • 端末内の記録：アプリを削除すると直ちに端末から削除されます。提供者のサーバーには保管されません。本サービスは Android の端末バックアップと端末間の移行からアプリデータを除外しています。
  • Google ドライブのバックアップ：利用者本人のドライブに最新3件まで保管されます。新たにバックアップして3件を超えると最も古いものが削除されます。「Drive から復元」の一覧から1件ずつ削除でき、「アカウント連携を解除してバックアップを削除」ですべて直ちに削除されます。「ログアウト」のみの場合はバックアップが残り、再び連携して復元できます。
  • 広告 ID などの診断情報：Google の関連ポリシーと保有期間に従います。

第4条（破棄の手続きと方法）

  • 手続き：アプリ内で「ログアウト」、「アカウント連携を解除してバックアップを削除」、バックアップ1件の削除を実行するか、アプリを削除すると、承認手続きなしに直ちに処理されます。
  • 方法：端末内データは端末のストレージから削除され、Google ドライブのバックアップファイルは Google Drive API を通じて復元できないよう削除されます。

第5条（利用者の権利と行使方法）

利用者はアプリ内でいつでも次の権利を自ら行使できます。

  • ドライブのバックアップを1件削除（パスポート > アカウント · バックアップ > Drive から復元 > 削除）：選んだバックアップのみ削除
  • ドライブのバックアップをすべて削除（パスポート > アカウント · バックアップ >「アカウント連携を解除してバックアップを削除」）：Google ドライブ内のバックアップをすべて削除し、アプリへのドライブ権限を取り消し、アカウント連携を解除
  • ログアウト（パスポート > アカウント · バックアップ > ログアウト）：アカウント連携情報のみ削除（ドライブのバックアップと端末の学習記録はそのまま）
  • 通知のオフ・権限の解除：パスポート > 通知でオフにするか、システム設定で通知権限を解除（通知のみ停止し、学習機能はそのまま）
  • アプリの削除：端末に保存されたすべての設定と学習記録が一緒に削除されます

そのほか個人情報に関するお問い合わせは wwwtaekyu@gmail.com までご連絡ください。提供者は遅滞なく対応します。

第5条の2（児童の個人情報の保護）

本サービスは小学生を含むすべての年齢の方が利用できます。初回起動時に生まれた年を尋ね、14歳未満である、またはその可能性がある利用者（生まれた年のみで判断するため14歳の一部を含み、生まれた年を選ぶ前も同様。以下「児童利用者」）には次のように提供します。

  • アカウント連携とドライブのバックアップを提供しません。したがって提供者は児童利用者のメールアドレスなどのアカウント情報を処理せず、保護者の同意が必要な個人情報を収集しません。
  • 広告は児童向けとしてリクエストします。Google AdMob に児童向け（child-directed）・同意年齢未満として示し、全年齢（G）の広告のみを受け取ります。この場合パーソナライズ広告は表示されず、Google は児童向けリクエストに関する自社ポリシーに従い広告 ID などの利用を制限します。
  • 生まれた年は利用者の端末にのみ保存され、外部に送信されません。

保護者はメールで児童利用者の個人情報の閲覧・削除などを求めることができます。ただし提供者は児童利用者の個人情報を別途保管しておらず、端末のデータはアプリの削除ですべて消去されます。

第6条（安全管理措置）

  • 技術的措置：設定と学習記録は端末内に保存され、利用者がドライブのバックアップを実行する場合を除き外部に送信されません。Google アカウントの認証は Google の標準 OAuth を使い、Google ドライブとの通信は TLS で暗号化されます。バックアップは利用者本人のドライブ内のアプリ専用非公開領域（appDataFolder）に保存されます。ただし、バックアップはエンドツーエンド暗号化ではなく、Google アカウントのセキュリティに依存します。
  • 管理的措置：個人情報を取り扱う担当者を最小限にしています。

第7条（委託・第三者提供）

提供者は利用者の学習データを保管する独自のサーバーを運営していません。以下の目的のために次の事業者のサービスを利用し、各サービスで処理される情報は当該事業者のプライバシーポリシーに従います。

目的利用サービス処理される情報
アカウント連携Google アカウント認証（Google LLC）メールアドレス、アカウント識別子
学習記録のバックアップ・復元Google Drive API — appDataFolder（Google LLC）設定と学習記録
広告の掲載Google AdMob（Google LLC）広告 ID、IP アドレス、端末情報、診断データ

Google プライバシーポリシー：https://policies.google.com/privacy

第8条（アプリの権限）

本サービスは次の権限を、記載の目的にのみ使用します。

  • 通知（POST_NOTIFICATIONS）：利用者がオンにした学習通知を表示するためだけに使います。初回設定または通知設定で求め、許可しなくても通知以外のすべての機能を利用できます。
  • 起動完了の受信（RECEIVE_BOOT_COMPLETED）：端末の再起動後に学習通知を再予約するためだけに使います。
  • インターネット（INTERNET）：Google アカウント連携、Google ドライブのバックアップ・復元、広告の掲載にのみ使います。
  • 広告 ID（AD_ID）：広告 SDK が広告の配信と測定に使います。

本サービスはマイク・SMS・連絡先・通話履歴・位置情報・写真・ファイルへのアクセス権限を求めません。

第9条（広告サービス）

本サービスは Google AdMob でバナー広告を掲載します。広告のパーソナライズのために広告 ID などが収集されることがあり、利用者は端末の設定（設定 > プライバシー > 広告）で広告のカスタマイズをオフにしたり、広告 ID をリセット・削除したりできます。家族で使うアプリとして、14歳以上の利用者にも保護者の指導が望ましい水準（PG）以下の広告のみをリクエストし、児童利用者には第5条の2を適用します。欧州経済領域（EEA）・英国・スイスなど別途同意が必要な地域では、Google の同意管理プラットフォーム（UMP）で同意手続きを案内し、同意前には広告 SDK を初期化しません。
